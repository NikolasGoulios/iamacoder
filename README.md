# 🧠 I Am a Coder

A playful micro-web experience that captures the chaotic brilliance of being a developer — yes, including debugging your own existence.

## 💡 Concept

This project is a minimalist webpage that displays a rotating quote with developer humor. Every time you tap or click anywhere on the screen, the quote updates. It’s a fun little tribute to the coder lifestyle.

## 🚀 Features

- Clean, responsive design
- Tap or click anywhere to refresh the quote
- SVG GitHub icon linking to the project repo
- Tech-inspired aesthetic and tone

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

## 📁 Project Structure

/iamacoder
├── index.html        # Main HTML structure
├── style.css         # Styling for layout and text
└── script.js         # Handles interactivity and quote logic
